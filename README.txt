GROUP 3 + GROUP 8 MINI WEBSITE PROJECT

Pages:
- index.html: Home
- gallery.html: Gallery
- blog.html: Blog
- contact.html: Contact form
- personal-homepage.html: Group 3 personal homepage

Keep style.css, script.js, favicon.svg and the images folder together with all HTML pages.
The contact form is a front-end demonstration only. It does not send or store messages.

PHONE PREVIEW NOTE:
Some Android file previews open HTML pages with a content:// address and block access to nearby CSS, JavaScript and image files. This can make a working multi-file site look unstyled when opened locally. The shared stylesheet and script are intentionally separate to meet the assignment requirements. Once the complete folder is published together on GitHub Pages or Netlify, the browser can load the linked files normally.

PUBLISHING:
Upload the complete contents of this folder to a GitHub repository, then enable GitHub Pages from the repository's Settings > Pages. Do not upload only index.html; upload the CSS, JavaScript and images too.

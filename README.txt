PROJECT 3 AND PROJECT 8

PROJECT 8 (main website)
- Open index.html for the Home page.
- Other pages: gallery.html, blog.html, contact.html.
- styles.css contains the shared design.
- script.js controls the mobile navigation and contact form demonstration.
- images/ contains local SVG images used in the gallery and home page.

PROJECT 3
- Open project-3/index.html.
- project-3/styles.css contains its styling.
- project-3/favicon.svg is the browser-tab icon.

REFLECTIONS
- REFLECTIONS.md contains the Project 3 group reflection, Project 8 group reflection,
  and the short reflection on advanced HTML5 features.

GITHUB PAGES
To publish the mini website from the repository root, keep index.html, gallery.html,
blog.html, contact.html, styles.css, script.js, images/, and project-3/ in the root.
Enable GitHub Pages from the main branch and the root folder.

NOTE
The contact form is a front-end demonstration. It validates required fields in the
browser and displays a confirmation, but it does not deliver or store messages.

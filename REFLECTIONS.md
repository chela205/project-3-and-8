# Project 3 and Project 8 — Group Reflections

## Project 3: Personal Homepage

For Project 3, we created a personal homepage using the basic structure of an HTML document. We organised the information into three sections: About Me, Education, and Interests. We added a page title, description, keywords, author information, internal navigation, and a favicon. We also used CSS to improve the layout, colours, spacing, and readability.

What worked well was dividing the information into clear sections and using anchor links to move around the page. The styling also helped the page look more organised on both large and small screens. While checking the website, we noticed that links and file paths need to match the names and locations of the files exactly. We checked the navigation and corrected the paths so that the page resources could be found. This project helped us understand how the HTML document structure, metadata, CSS, and favicon work together.

## Project 8: Mini Website

For Project 8, we built a four-page mini website called *The Little Things*. It contains Home, Gallery, Blog, and Contact pages. We used one external CSS file to keep the appearance consistent and added a responsive navigation menu so visitors can move between pages on different screen sizes. The gallery uses a grid layout, the blog contains two posts with useful links, and the contact page includes labelled form fields, radio buttons, checkboxes, a dropdown list, and a message area.

One challenge during development was keeping the page links and image file names consistent. An image did not display when its file name and the path in the HTML did not match. We checked the image references and used working local image files. We also separated the content for the personal homepage from the four pages of the mini website so that the two projects would not be mixed together. Testing the pages helped us identify and correct these issues.

## Project 8: Short Reflection on Advanced HTML5 Features

Modern web development uses HTML5 features to make websites more useful, accessible, and interactive. Elements such as `video` and `audio` allow media to be included directly in a webpage with playback controls. The `canvas` element provides a space where JavaScript can draw graphics, animations, and simple visualisations. Semantic elements such as `header`, `nav`, `main`, `section`, and `footer` give webpage content a clearer structure. Forms also support useful input types and built-in validation, helping users enter information correctly.

Responsive design is another important part of modern websites. The `picture` element and responsive image techniques can provide suitable images for different screen sizes, while CSS media queries help a layout adapt to phones, tablets, and computers. These features improve usability and can make websites easier to navigate across devices.

While working on our mini website, we used semantic page structure, a responsive layout, an interactive navigation menu, and a contact form with browser validation. To learn more about advanced HTML5 features, we referred to the MDN tutorials on the [Canvas API](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial), the [HTML video element](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/video), and the [HTML audio element](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/audio). We found that HTML provides the structure, CSS controls presentation, and JavaScript adds behaviour. When these technologies are used together, they make it possible to create websites that are organised, accessible, responsive, and engaging.

Overall, the projects helped us practise building webpages, linking separate files, styling content, and checking our work in a browser. We learned that testing is important because even a small mistake in a file name or link can stop part of a website from working.

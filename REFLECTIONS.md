# Project 3 and Project 8 Reflections

## Project 8 group reflection
We worked together to plan and build a small website with four connected pages. We used HTML to organise the content, CSS to create a consistent appearance and JavaScript for the responsive navigation menu and demonstration contact-form response. One challenge was keeping the navigation and styling consistent across all pages. We addressed this by reusing the same navigation structure and stylesheet. We also checked the image paths and page links so that visitors could move between the pages.

## Advanced HTML5 features reflection
While learning about modern HTML5, we explored features such as the canvas element for drawing graphics, the audio and video elements for embedding media, and semantic elements that give page content clearer meaning. These features can make websites more interactive and accessible when they are used appropriately. We referred to the MDN learning resources to understand how they work.

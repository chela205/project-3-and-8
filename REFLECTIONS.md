Project 3 and Project 8 Reflections

Project 3: Personal Homepage

We created a personal homepage using HTML and CSS. The website contains sections for an introduction, education and interests. We also added page metadata and a favicon to improve the website.

One thing that worked well was organising the information into clear sections. A challenge was making the page look neat and readable. We addressed this by using CSS to add spacing, colours and consistent styling. We also checked that the stylesheet and favicon were correctly linked.

Project 8: Mini Website

Reflection on Advanced HTML5 Features

HTML5 provides features that make modern websites more interactive, meaningful and accessible. During our research, we explored features such as the "<canvas>", "<video>" and "<audio>" elements.

The "<canvas>" element allows developers to create graphics and drawings directly on a webpage using JavaScript. It can be used for animations, games and data visualisations.

The "<video>" element allows videos to be embedded directly into webpages without requiring external video players. Similarly, the "<audio>" element allows sound and music to be included on websites.

HTML5 also provides semantic elements such as "<header>", "<nav>", "<main>" and "<footer>". These help organise webpage content and make its structure easier for browsers, developers and assistive technologies to understand.

In conclusion, HTML5 features improve the functionality and organisation of websites. They allow developers to create more interactive and user-friendly experiences.

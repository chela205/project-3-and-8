Learning by building

Creating a website is a practical way to understand how different parts of the web work together. HTML gives a page its structure, CSS controls its appearance, and JavaScript can add interaction.

Helpful resource: MDN — Getting started with the web.

Making the web accessible

Good websites should be clear and easy to use. Descriptive headings, meaningful link text, image alternative text and a layout that works on small screens all help visitors.

Helpful resource: MDN — Accessibility.
